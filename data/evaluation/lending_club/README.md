# LendingClub Loan Data (En Evaluación / Respaldo)

Este directorio almacena la referencia y datos de LendingClub para riesgo crediticio y FinTech.

## Fuente Oficial
- **Kaggle**: [Lending Club Loan Data](https://www.kaggle.com/datasets/wordsforthewise/lending-club)
- **Open Data alternativa**: [Consumer Financial Protection Bureau (CFPB)](https://www.consumerfinance.gov/data-research/consumer-complaints/)

## Características Clave
- +1M a 2.2M de observaciones históricas de préstamos.
- +100 variables socioeconómicas y financieras (tasa de interés, ingresos verificados, grado de crédito, historial de morosidad, estado del préstamo).
- Objetivo principal: Clasificación de impago (*Default*) vs. pago completo (*Fully Paid*).
